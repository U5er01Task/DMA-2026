## 1. Золотое правило верстки Flutter: Ограничения, Размеры и Позиции

Вся верстка во Flutter подчиняется трем строгим правилам:

1. **Ограничения спускаются вниз** (Constraints go down): Родитель передает дочернему элементу минимальную и максимальную допустимую ширину и высоту (`BoxConstraints`).
2. **Размеры поднимаются вверх** (Sizes go up): Дочерний элемент выбирает свой желаемый размер строго в рамках переданных ограничений и сообщает его родителю.
3. **Родитель задает позицию** (Parent sets position): Родитель решает, в каких координатах экрана `(x, y)` разместить дочерний элемент.

```
       Родитель (Scaffold / Column)
              │
              │ 1. Ограничения (Ширина: 0..400, Высота: 0..800)
              ▼
       Дочерний виджет (Container)
              │
              │ 2. Размер (Ширина: 250, Высота: 60)
              ▼
       Родитель позиционирует потомка (x: 75, y: 120)
```

> [!WARNING]
> Если виджет игнорирует ограничения родителя, возникает ошибка переполнения экрана (знаменитая полосатая желто-черная разметка **A RenderFlex overflowed by X pixels**).

## Тема 1. Базовые одиночные контейнеры: Container, SizedBox, Padding, Align

### Сравнение контейнеров по производительности

| Виджет                 | Назначение                               | Когда использовать                                     | Внутреннее устройство                  |
| :--------------------- | :--------------------------------------- | :----------------------------------------------------- | :------------------------------------- |
| **`SizedBox`**         | Фиксированные ширина и высота            | Жесткий размер или пустой отступ между кнопками        | Легковесный `RenderConstrainedBox`     |
| **`Padding`**          | Внутренние отступы со всех сторон        | Отступ контента от границ                              | Легковесный `RenderPadding`            |
| **`Align` / `Center`** | Позиционирование потомка внутри          | Прижатие к углам (`Alignment.bottomRight`)             | Легковесный `RenderPositionedBox`      |
| **`Container`**        | Комбайн: цвет, скругления, тени, бордеры | Только когда нужна сложная декорация (`BoxDecoration`) | Состоит из 5–7 вложенных микровиджетов |

### Пример использования BoxDecoration

```dart
import 'package:flutter/material.dart';

Widget buildPromoCard() {
  return Container(
    width: double.infinity, // Растянуть на всю ширину родителя
    padding: const EdgeInsets.symmetric(horizontal: 20, vertical: 16),
    margin: const EdgeInsets.all(16),
    decoration: BoxDecoration(
      color: Colors.white,
      borderRadius: BorderRadius.circular(16),
      // Мягкая тень карточки
      boxShadow: [
        BoxShadow(
          color: Colors.black.withOpacity(0.08),
          blurRadius: 12,
          offset: const Offset(0, 4),
        ),
      ],
      border: Border.all(color: Colors.deepPurple.shade100, width: 1.5),
    ),
    child: const Text('Карточка специального предложения'),
  );
}
```

## Тема 2. Многоэлементная компоновка: Row, Column, Stack, Wrap

### Оси выравнивания в Row и Column

- **MainAxisAlignment (Главная ось):** Горизонтальная для `Row`, вертикальная для `Column`.
- **CrossAxisAlignment (Поперечная ось):** Вертикальная для `Row`, горизонтальная для `Column`.

```
         ROW (Горизонталь)                         COLUMN (Вертикаль)
┌─────────────────────────────────┐       ┌─────────────────────────────────┐
│ [Item 1]   [Item 2]   [Item 3]  │       │ [Item 1]                        │
└─────────────────────────────────┘       │ [Item 2]                        │
   Главная ось ──────────────►            │ [Item 3]                        │
                                          └─────────────────────────────────┘
                                             Главная ось вниз ▼
```

### Управление гибкостью: Expanded vs Flexible vs Spacer

- `Expanded`: Заставляет элемент занять **всё** оставшееся свободное пространство главной оси (`flex: 1`).
- `Flexible`: Позволяет элементу занять пространство, но не принуждает растягиваться, если контент меньше (`fit: FlexFit.loose`).
- `Spacer()`: Пустая растягивающаяся пружина между элементами (синтаксический сахар для `Expanded(child: SizedBox())`).

### Пример Stack (Слои наложения) и Wrap (Автоперенос)

```dart
// 1. Stack: Наложение бейджа поверх картинки
Widget buildProductBadge() {
  return Stack(
    clipBehavior: Clip.none, // Разрешить выход за границы
    children: [
      Container(width: 80, height: 80, color: Colors.grey.shade300),
      Positioned(
        top: -6,
        right: -6,
        child: Container(
          padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
          decoration: BoxDecoration(color: Colors.red, borderRadius: BorderRadius.circular(10)),
          child: const Text('NEW', style: TextStyle(color: Colors.white, fontSize: 10)),
        ),
      ),
    ],
  );
}

// 2. Wrap: Список тегов с переносом на новую строку
Widget buildTagCloud(List<String> tags) {
  return Wrap(
    spacing: 8.0, // Расстояние между тегами по горизонтали
    runSpacing: 4.0, // Расстояние между строками по вертикали
    children: tags.map((tag) => Chip(label: Text(tag))).toList(),
  );
}
```

## Тема 3. Списки и прокручиваемые области: ListView, GridView, ScrollView

Когда контент не помещается на экране смартфона или имеет динамическую длину, используются прокручиваемые виджеты.

### Сравнение механизмов списков

| Виджет                      | Механизм работы                                     | Потребление памяти           | Назначение                             |
| :-------------------------- | :-------------------------------------------------- | :--------------------------- | :------------------------------------- |
| `SingleChildScrollView`     | Рендерит все элементы сразу в память                | Высокое (нет виртуализации)  | Статичные формы ввода, экраны настроек |
| `ListView(children: [...])` | Создает все виджеты сразу                           | Высокое                      | Короткие списки до 10–15 элементов     |
| `ListView.builder`          | **Виртуализация:** создает элементы по мере скролла | Минимальное (только видимые) | Длинные ленты новостей, каталоги       |
| `ListView.separated`        | Виртуализация + разделители                         | Минимальное                  | Списки с полосами-разделителями        |
| `GridView.builder`          | Двумерная сетка с виртуализацией                    | Минимальное                  | Плитки интернет-магазинов, фотогалереи |

### Пример высокопроизводительного списка

```dart
class CatalogListView extends StatelessWidget {
  final List<String> products;

  const CatalogListView({super.key, required this.products});

  @override
  Widget build(BuildContext context) {
    return ListView.separated(
      itemCount: products.length,
      // Физика прокрутки: пружинящий скролл iOS на всех платформах
      physics: const BouncingScrollPhysics(),
      separatorBuilder: (context, index) => const Divider(height: 1),
      itemBuilder: (context, index) {
        return ListTile(
          leading: CircleAvatar(child: Text('${index + 1}')),
          title: Text(products[index]),
          subtitle: const Text('В наличии на складе'),
          trailing: const Icon(Icons.chevron_right),
          onTap: () => print('Выбран товар $index'),
        );
      },
    );
  }
}
```

2. **Виртуализированный каталог на 10 000 элементов:** Создайте `ListView.builder` на 10 000 строк и убедитесь в плавной прокрутке без лагов памяти.
3. **Сетка фотогалереи 3х3:** Настройте `GridView.count` с параметром `crossAxisCount: 3` и квадратными пропорциями ячеек.

## Тема 4. Интерактивные элементы, кнопки и обработка жестов

### Семейство кнопок Material 3

- `ElevatedButton`: Кнопка с мягкой тенью для основных действий.
- `FilledButton`: Залитая цветом кнопка для ключевого целевого действия на экране.
- `OutlinedButton`: Контурная кнопка для нейтральных действий (например, «Отмена»).
- `TextButton`: Текстовая кнопка без рамок для второстепенных действий.
- `IconButton`: Компактная круглая кнопка-иконка.

### Обработка касаний: InkWell против GestureDetector

| Параметр                       | `InkWell`                                    | `GestureDetector`                                         |
| :----------------------------- | :------------------------------------------- | :-------------------------------------------------------- |
| **Material Ripple Effect**     | **Есть** (чернильная волна по гайдлайнам)    | **Нет** (чистое перехватывание без анимации)              |
| **Требование предка Material** | Обязан находиться внутри виджета `Material`  | Работает в любой точке дерева                             |
| **Сложные жесты**              | Только `onTap`, `onDoubleTap`, `onLongPress` | Мультитач, масштабирование (Pinch), панорамирование (Pan) |

```dart
// 1. InkWell с красивым эффектом всплеска
Widget buildCardWithRipple(VoidCallback onTap) {
  return Material(
    color: Colors.transparent,
    child: InkWell(
      onTap: onTap,
      borderRadius: BorderRadius.circular(12),
      splashColor: Colors.deepPurple.withOpacity(0.2),
      child: const Padding(
        padding: EdgeInsets.all(16.0),
        child: Text('Кликни с чернильным эффектом!'),
      ),
    ),
  );
}

// 2. GestureDetector: Обработка свайпа карточки
Widget buildSwipeableBox() {
  return GestureDetector(
    onHorizontalDragEnd: (details) {
      if (details.primaryVelocity! > 0) {
        print('Свайп вправо');
      } else if (details.primaryVelocity! < 0) {
        print('Свайп влево');
      }
    },
    child: Container(width: 200, height: 100, color: Colors.amber),
  );
}
```

## Тема 5. Формы ввода и валидация данных: TextFormField, Switch, Checkbox

Для сбора данных используются специализированные виджеты форм, поддерживающие строгую валидацию и сохранение состояния.

### Связка Form и GlobalKey

Виджет `Form` объединяет несколько полей `TextFormField` и проверяет их состояние одним вызовом метода `formKey.currentState!.validate()`.

```dart
class LoginForm extends StatefulWidget {
  const LoginForm({super.key});

  @override
  State<LoginForm> createState() => _LoginFormState();
}

class _LoginFormState extends State<LoginForm> {
  final _formKey = GlobalKey<FormState>();
  final _emailController = TextEditingController();
  bool _rememberMe = false;

  @override
  void dispose() {
    _emailController.dispose();
    super.dispose();
  }

  void _submitForm() {
    // Запуск валидации всех полей внутри Form
    if (_formKey.currentState!.validate()) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Вход: ${_emailController.text}')),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Form(
      key: _formKey,
      child: Column(
        children: [
          TextFormField(
            controller: _emailController,
            keyboardType: TextInputType.emailAddress,
            decoration: const InputDecoration(
              labelText: 'Электронная почта',
              prefixIcon: Icon(Icons.email),
              border: OutlineInputBorder(),
            ),
            // Логика валидации
            validator: (value) {
              if (value == null || value.trim().isEmpty) {
                return 'Введите адрес почты';
              }
              if (!value.contains('@')) {
                return 'Некорректный формат email';
              }
              return null; // Ошибок нет
            },
          ),
          const SizedBox(height: 16),
          CheckboxListTile(
            title: const Text('Запомнить меня на этом устройстве'),
            value: _rememberMe,
            onChanged: (val) => setState(() => _rememberMe = val ?? false),
            controlAffinity: ListTileControlAffinity.leading,
          ),
          const SizedBox(height: 24),
          FilledButton(
            onPressed: _submitForm,
            child: const Text('Войти в аккаунт'),
          ),
        ],
      ),
    );
  }
}
```
