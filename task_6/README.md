# Android80

Практическая работа по Services, Broadcast Receivers и Content Providers. Java, `com.university.app`.

Выполнил: Ануфриев Д., П24-3.2.

## Модули

- `app` — основное приложение, 80 кнопок на главном экране
- `client` — второе приложение (задание 24, корзина через провайдер)
- `receiver_mid`, `receiver_low` — ресиверы из отдельных модулей (задание 19, порядок ordered broadcast)

## Сборка и запуск

1. Открыть папку в Android Studio (JDK 17, Android SDK 35) и дождаться Gradle Sync.
2. Установить `app` и `client` на телефон (оба должны быть подписаны одним ключом).
3. Нажать нужную кнопку или выполнить `adb shell am start -n com.university.app/.MainActivity --ei task N`.
4. Логи: `adb logcat | grep A80` (в PowerShell: `adb logcat | findstr A80`).

## Кнопка «■ Стоп»

Рядом с каждым из 80 заданий есть кнопка «■ Стоп». Она останавливает службы, Worker, ресиверы, наблюдатели и будильник этого задания. Если звук плеера или геозоны не затихает, нажмите «Стоп» у запущенного задания (1.2, 2, 5, 34), переустанавливать приложение не нужно. Разовые действия (запрос в базу, диалог) кнопка только сбрасывает.

## Скриншоты для отчёта

`bash scripts/run_all.sh` собирает и ставит приложение, выдаёт разрешения, снимает экран и шторку для всех 80 заданий и собирает `evidence/report.md`.

## Файлы

- `REPORT.md` — отчёт с блоками под скриншоты (`evidence/task_NN.png`)
- `CHECKLIST.md` — что запускать и что снимать на каждом задании
- `ADB_COMMANDS.md` — команды `adb`
- `EXPLANATIONS.docx` — объяснение всех заданий и вопросы к защите
